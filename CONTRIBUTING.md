# Contributing to RepoCare

Thanks for considering a contribution. RepoCare is early, so clear examples and careful feedback are especially useful.

## Before opening an issue

- Search existing issues for the same problem.
- For a bug, include the command you ran, Python version, and a short redacted error message.
- Never include a GitHub token, private repository URL, or other credential.
- For a feature, describe the maintainer problem it solves and how the output should help.

## Pull requests

1. Keep changes focused and explain the user-facing problem.
2. Preserve RepoCare's read-only behavior and disclose any new network request or data handling.
3. Update the README when command behavior or privacy scope changes.
4. Include a concise summary and any manual verification performed.

Contributions are reviewed on their merits. Opening a pull request does not guarantee it will be merged.
